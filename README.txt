TARUN PRAGADA PORTFOLIO - ASSET SETUP

Copy the contents of this folder into your existing Vite project.

Files:
- src/App.jsx
- src/index.css
- public/profile.jpg
- public/Tarun-Pragada-Resume.pdf

Make sure src/main.jsx contains:
import './index.css';

Then run:
npm run dev

The Live Demo button has been removed.
The project button opens GitHub.
The Resume button downloads the supplied resume PDF.
The hero card uses the supplied profile photo.
